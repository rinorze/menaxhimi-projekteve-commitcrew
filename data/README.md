# Data

Curated place data, import scripts and image attributions.

- `places/<region>.csv`: one row per place (name sq/en, description sq/en, category, lat, lng, check-in radius, municipality). Each region has one owner (see the project plan).
- `scripts/`: imports candidate places from OpenStreetMap (Overpass) and Wikidata/Wikimedia Commons.
- `attributions.csv`: `image_url, author, license, source_url` for **every** image we use. Only Wikimedia Commons (CC BY / CC BY-SA / CC0), our own photos, or photos with written permission are allowed.

Map data © OpenStreetMap contributors (ODbL). Boundaries: geoBoundaries (CC BY 4.0).
