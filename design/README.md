# Design assets

Exported, production-ready assets used by the apps. Source files live in Figma; see the [design brief](../docs/design/DESIGN-BRIEF.md).

```text
design/
  tokens.json      Design tokens exported from Figma → generated into packages/shared/theme
  brand/           Logo, app icon, splash, share-card template
  icons/           Category and UI icons (SVG)
  stamps/          Region stamp frames and event stamp artwork (SVG)
  map-style/       MapLibre style JSON (light / dark) made in Maputnik
  motion/          Lottie animations (stamp, like, level-up)
```
